# discord.cpp-self v0.1

First public prerelease of an independent C++20 library for Discord user accounts.
The GitHub tag is `v0.1`; CMake, Conan, vcpkg and `discord::version` use `0.1.0`.

This release provides messaging and history, DMs, visible profiles and memberships,
a small own-message command router, Gateway reconnect/resume and rate-limit-aware
REST. The CMake package supports static and shared builds with target `discord::self`.

Documentation, examples, offline HTTP/WebSocket fixtures, source packaging and
LGPL-3.0-or-later notices are included. Source archives do not bundle dependencies
or runtime DLLs.

## Download and install

- `discord.cpp-self-v0.1.tar.gz` / `.zip`: the complete source distribution.
- `discord.cpp-self-v0.1-vcpkg-overlay.zip`: a port pinned to this release's commit,
  with the verified upstream source SHA512.
- `SHA256SUMS`: checksums for all three assets.

Use CMake with target `discord::self`, build the included Conan 2 recipe, or use
the overlay with vcpkg. See [installation](../DISTRIBUTION.md). The Conan recipe
is included in both source archives; a central registry listing is not required.

## Known limits

- Early API; not a complete port of discord.py-self and not a bot-token library.
- No custom embed sender, file upload, voice/video or coroutine REST interface.
- Rate limiting is per client; REST calls are serialized.
- Historical live messaging/DM/profile tests passed; friend-request completion
  required CAPTCHA, and subsequent account/token failures were observed.
- Live edit/delete, macOS and MSVC runtime validation remain outstanding.
- Discord prohibits user-account automation; this library does not bypass account
  verification, CAPTCHA or platform restrictions.

See the README, API reference, comparison and validation notes for precise scope.
